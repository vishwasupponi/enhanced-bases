# Enhanced Bases for Obsidian

Original GoodBases Enhanced. A Notion-styled database view for your Obsidian vault.

## Features
- **Notion-Style Tables**: Beautiful, native-feeling table views.
- **Color Pill Customization**: Choose from vibrant presets or use the custom color wheel for your properties.
- **Adjustable Layouts**: Resize columns dynamically with a clean right-side padding gap.
- **Sticky Headers**: Scroll through massive databases while keeping your headers frozen at the top.
- **Smart Date Formatting**: Dates are natively rendered in standard `DD-MM-YYYY HH:MM AM/PM` formats.

## Manual Installation
1. Download the latest release (`main.js`, `manifest.json`, `styles.css`).
2. Create a folder named `enhanced-bases` inside your `.obsidian/plugins/` directory.
3. Place the downloaded files inside that folder.
4. Reload Obsidian and enable the plugin in Community Plugins.

## Development
To build the plugin from source:
```bash
npm install
npm run build
```
